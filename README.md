# Redstone Energy HVAC Calculator

Redstone-branded fork of the [HVAC Calculator](https://github.com/DanKnowsAGuy-web/hvac-calculator).

Same `compute()` engine and math as the original. Presentation only is rebranded: Redstone Energy wordmark, red/stone palette, Redstone copy.

## Live

**https://slashyourenergycost.com/redstone-calculator/**

Same pattern as the original at [slashyourenergycost.com/hvac-calculator](https://slashyourenergycost.com/hvac-calculator/).

## Files

- `index.html` — the calculator (engine untouched)
- `redstone-logo.png` — official Redstone Energy wordmark
- `.nojekyll` — GitHub Pages serves the folder as-is

## The rule

Nothing that produces a number was edited. Same inputs yield the same outputs as the source calculator.
